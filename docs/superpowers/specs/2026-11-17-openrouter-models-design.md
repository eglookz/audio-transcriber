# OpenRouter-модели в transcribe.py — дизайн

Дата: 2026-11-17. Размер: небольшая доработка (`transcribe.py`, README, `.env.example`).

## Зачем

Сравнение на реальных записях (деловая встреча + две консультации, русский язык)
показало, что `whisper-1` — текущая модель по умолчанию — заметно уступает моделям,
доступным через OpenRouter:

| Модель | $/час | Итог сравнения |
|---|---|---|
| `microsoft/mai-transcribe-2` | 0.10 | 1-е место: точнее всех, имена и термины верно, реплики собеседника отдельными сегментами |
| `mistralai/voxtral-small-transcribe-3-0` | 0.24 | 2-е: чистый текст без «э-э», местами путается в перебиваниях |
| `elevenlabs/scribe-v2` | 0.22 | 3-е: гладко, но подменяет слова правдоподобными («пять морей») |

Цель — чтобы при запуске можно было назвать любую из этих моделей
(`--model mai` / `voxtral` / `scribe`) и получить расшифровку ею.

## Цели

- Выбор победителей через `--model`, короткими алиасами и полными id OpenRouter.
- Модель по умолчанию — `microsoft/mai-transcribe-2` (*моё решение*: лучшая и самая дешёвая;
  требует `OPENROUTER_API_KEY`).
- Всё, что работает сейчас через OpenAI напрямую (`whisper-1`, `gpt-transcribe`,
  `gpt-4o-transcribe-diarize`, `--prompt`, `--speakers`), продолжает работать как раньше.
- Любая другая STT-модель OpenRouter принимается по полному id (`--model x-ai/grok-stt-2.0`).
- `.srt` / `.timestamped.txt` для всех трёх победителей, включая Scribe.

## Не цели (пока)

- Диаризация через MAI-2 (`provider.options.azure.diarization`).
- Словарь терминов через `provider.options` (Voxtral context biasing, Scribe keyterms).
- Перевод whisper-1 и прочих OpenAI-моделей на OpenRouter.

## Анти-цели

- Сломать текущий запуск для OpenAI-моделей или кэш уже нарезанных чанков.
- Молча тратить деньги на неизвестную модель с опечаткой в имени.

## Подходы

- **A. Два провайдера, выбор по имени модели** — *выбран*. У `ModelSpec` появляется
  провайдер; клиент `OpenAI(...)` создаётся с нужными `base_url` и ключом.
- **B. Всё через OpenRouter** — отклонён: теряются `gpt-4o-transcribe-diarize` и `--prompt`.
- **C. Любая модель OpenRouter по полному id** — *взят в придачу к A*.

## Как устроено

**Провайдер и клиент.**
- `ModelSpec` получает поле `provider: "openai" | "openrouter"`.
- Для `openrouter` клиент — `OpenAI(base_url="https://openrouter.ai/api/v1", api_key=OPENROUTER_API_KEY)`.
  Запрос тот же: `client.audio.transcriptions.create(...)`, multipart (проверено: работает).
- Ключ ищется в env или `.env` по провайдеру выбранной модели. Сообщение об отсутствии ключа —
  со ссылкой на https://openrouter.ai/settings/keys.

**Модели и алиасы.**
- В `MODEL_SPECS` добавляются три победителя с полными id.
- Алиасы: `mai`, `voxtral`, `scribe` → полные id.
- Все три победителя: `response_format=verbose_json`, `timestamps=True`,
  `supports_prompt=False`, `temperature` поддерживается, `price_per_minute` из API OpenRouter:
  - MAI — $0.00167/мин;
  - Voxtral — $0.004/мин;
  - Scribe — $0.00367/мин.
- `--model` больше не ограничен `choices`: проверка своя.

**Произвольная модель (C).** Если id содержит `/` и его нет в `MODEL_SPECS`:
- тулза запрашивает `GET /api/v1/models?output_modalities=transcription` без ключа:
  - id не найден — ошибка до любых трат, с подсказкой похожих id;
  - найден — берётся цена для оценки стоимости;
  - сеть недоступна — предупреждение, работа продолжается.
- Используется консервативный спек: `verbose_json` с таймкодами. Если модель ответит 400,
  срабатывает уже существующий откат на `json` без таймкодов.
- `--list-models` показывает встроенные модели и подсказку, где смотреть остальные.

**Scribe и сегменты из слов.** Если ответ содержит `words`, но сегментов нет или он один
на весь чанк:
- сегменты собираются из слов: новый сегмент на паузе ≥ ~0.8 с или после знака конца
  предложения, когда сегмент уже длиннее ~15 с;
- для Scribe запрашивается `timestamp_granularities=["word", "segment"]`.

Это общий механизм в разборе ответа, не завязанный на имя модели.

**Ошибки OpenRouter.**
- 402 с `metadata.reason == "in_flight_budget_exhausted"` — повтор с ожиданием по
  `Retry-After` (уже ограничено 120 с).
- Прочие 402 (нет кредитов) — `FatalAPIError` с подсказкой пополнить баланс на
  https://openrouter.ai/settings/credits.
- 401 и 404 — как сейчас, но с текстом про OpenRouter.
- 400 «malformed audio» на OpenRouter не ожидается: тулза всегда шлёт перекодированный MP3.

**Прочее.**
- Кэш: подпись запроса уже включает модель, менять не нужно.
- `--prompt` с OpenRouter-моделью даёт существующее предупреждение «будет проигнорирован».
- Размер чанка по умолчанию 900 с подходит (MAI-2 отработала 26 минут одним запросом);
  `--workers` остаётся 4.
